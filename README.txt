YM Digital website

Files
- index.html: main homepage with TikTok portfolio links and analytics callout
- analytics.html: dedicated analytics page with metrics and supplied screenshots
- assets/: original analytics screenshots

Deploying on Vercel
1. Keep index.html, analytics.html, and the assets folder together in the project root.
2. If using Vercel static deployment, upload/deploy this folder or commit its contents to the connected Git repository.
3. The homepage links to analytics.html; keep that filename unchanged unless you also update the links.

Notes
- Analytics values are transcribed from the user-provided screenshots and are not live-connected to TikTok.
- TikTok profile links open in a new tab.
